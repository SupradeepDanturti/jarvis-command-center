G16 COMMAND CENTER

Meet Jarvis.

A laptop voice assistant controlled from your existing command surface.

First connection

  1. On the approved laptop browser, open More → Jarvis.
  2. Create an API key in your OpenAI account. Expand Manage API key if needed, then paste it into the password field and choose Save key. Do not paste it into a chat or source file.
  3. Choose Preview voice to hear the local synthetic Jarvis-style voice on the laptop.
  4. Choose Turn on Jarvis. Say “Hey Jarvis,” then your command. Speak toward the selected microphone. After Jarvis replies, answer within the follow-up window without saying Hey Jarvis again.

Try these

  • “Hey Jarvis, open YouTube.” Opens our registered YouTube shortcut in Brave.
  • “Hey Jarvis, open Discord.”
  • “Hey Jarvis, turn the volume down.” Sends one Windows volume step.
  • “Hey Jarvis, pause the music.” Toggles the current player once.
  • “Hey Jarvis, how much memory am I using?”
  • “Hey Jarvis, search NASA for a recent mission update.”

One laptop action per request. Arbitrary commands, URLs, installation, shutdown, and smart-home devices are not supported. Native web search is available for current information; source links appear beside replies.

Speakers and hardware alerts

Choose Jarvis speaker independently of your Windows default. Auto uses built-in Realtek speakers even when Windows audio goes to headphones; only real speaker outputs are listed. If the speaker is unavailable, Jarvis stops instead of switching to headphones. Preview voice tests that same speaker.

Alerts on / Alerts off switches warnings while Jarvis is running. CPU or RAM at 90%, or GPU temperature at 70°C, must appear in three fresh readings. Jarvis waits for idle wake listening, then speaks locally through Piper. All warnings share a one-hour cooldown across restarts. Alerts off cancels queued/current warning audio. Warnings are saved as system entries but are excluded from conversational memory.

The Iron Man activity HUD appears on Home after waking Jarvis, follows listening/thinking/speaking/follow-up phases and shows live readings over the black-hole artwork. It keeps touch controls available and respects reduced motion.

Natural follow-ups and history

Follow-up listening defaults to 15 seconds after a reply. Choose Off or 30 seconds in Jarvis settings while Jarvis is off. Within that window, speech is treated as the next conversation turn without the wake phrase. After silence, Jarvis returns to waiting for Hey Jarvis. Saying “thanks,” “that's all,” or “goodbye” ends the current conversation window.

Conversations are saved on this laptop and shown on the Jarvis screen. Earlier conversations loads more. Only the approved localhost owner can Clear history; this also stops Jarvis and clears its remembered context.

Your microphone and key

Wake-word detection and speech generation run locally on the CPU. After the wake word, a command clip of up to ten seconds is sent to OpenAI for transcription; the command text is sent for interpretation. Input closes while processing and speaking. Audio is not saved. Conversation text, action details and source links are saved privately on this laptop, up to the latest 500 exchanges. The six most recent exchanges provide OpenAI with conversation context when you start Jarvis again.

Closing this webpage keeps the laptop worker running. Turn off Jarvis to stop it and release its memory and microphone. It pauses while Windows is locked; a server restart starts with listening off. Any approved browser can control the switch. Only the approved laptop browser can save or remove a key. Windows encrypts the key for the current user; it never appears in API responses or browser storage.

OpenAI API usage needs API billing, separately from a ChatGPT subscription. “Saved” confirms private storage; it does not validate the key or your billing.

If local components are missing

On this project’s laptop, install the optional requirements and runtime models:

.venv\Scripts\python.exe -m pip install -r requirements-voice.txt
.venv\Scripts\python.exe scripts/install-voice.py

Restart the dashboard with scripts/restart-server.ps1 after installing new dependencies. Models are downloaded from the original Piper Jarvis and openWakeWord publishers into ignored private state. No other assistant’s frontend is installed.

Sound or connection problems

Check the default input and output devices in Windows Sound settings and allow desktop apps to access the microphone. Restart Jarvis after changing audio devices. If OpenAI rejects requests, check your key, API billing and internet access. A room TV or speaker can accidentally trigger the wake word; it is not speaker authentication.
